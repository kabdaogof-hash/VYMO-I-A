# VYMO AI — Studio créatif

Prototype web autonome et responsive pour un studio de création vidéo assisté par IA. L’interface et ses aperçus sont entièrement simulés côté client ; aucun service de génération ni facturation n’est connecté.

## Lancer le prototype

Ouvrez `index.html` dans un navigateur. Aucun build, serveur ou dépendance d’exécution n’est nécessaire. Une connexion Internet est utilisée uniquement pour charger les polices Google ; les polices système prennent le relais hors ligne.

## Interactions

- Navigation entre tableau de bord, studio, créations et offres.
- Modes texte en vidéo, image en vidéo et animation 3D.
- Modèles inspirants qui préremplissent la description.
- Génération d’un aperçu simulé avec décompte des crédits et mise à jour des créations pour la session en cours.

## Limites de la démo

Les vidéos ne sont pas réellement générées et les données ne sont pas conservées après fermeture ou rechargement de la page. Les crédits n’ont aucune valeur monétaire.
